# Why the packaging desk has no front end

The operator asks for a specification, checks the supporting evidence and records the decision. A database and a coding agent handle those changes. Printable HTML shows the week and the paperwork without a server.

A supplier portal, mobile camera capture, offline field work, drag-and-drop component trees and visual artwork proofing need an interface. This base does not provide them. It stores evidence references, not uploaded files or image proofs. Enterprise DNA scopes those features into the custom version where they matter.

The free base is for a trusted internal packaging operator, not an unauthenticated supplier or a shared production terminal. It has no user login or per-supplier permissions. Use Claude Code, Codex, OpenCode or Cursor with the same command library. Keep the database, drafts, source exports and evidence files private.
